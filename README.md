# 이야기 (Iyagi) - Reverse Image Search App

Android 앱에서 이미지/동영상의 원본을 찾아주는 역이미지 검색 애플리케이션입니다.

## 📱 주요 기능

- **다중 검색 엔진 지원**
  - Google Reverse Image Search
  - Yandex
  - Twitter/X
  - TinEye
  - Bing
  - Baidu

- **검색 기능**
  - 갤러리에서 이미지/동영상 선택
  - URL 직접 입력
  - 동시 다중 검색 엔진 검색

- **편의 기능**
  - 검색 기록 저장
  - 북마크 기능
  - 검색 결과 공유

## 🎯 요구사항

- Android 8.0 (API 26) 이상
- 인터넷 연결 필요

## 🚀 설치

1. 최신 APK를 [Releases](../../releases) 페이지에서 다운로드
2. APK 파일을 실행하여 설치

## 🛠️ 개발 정보

### 기술 스택
- **언어**: Kotlin
- **UI Framework**: Android Jetpack Compose / Material Design 3
- **웹 크롤링**: Jsoup
- **데이터베이스**: Room
- **네트워킹**: OkHttp + Retrofit
